<div class="t-label" style="color: var(--orange);">Installation et configuration</div>

<div class="grid grid-cols-2 gap-8 items-start">

<div>

1. Dans un terminal pour installer :

   ```bash
   curl -LsSf https://mistral.ai/vibe/install.sh | bash
   ```

2. Dans un nouveau terminal :

   ```bash
   vibe --setup
   ```

</div>

<div>

3. Configurer :

   - Choisissez votre thème
   - Sélectionnez « Launch browser »
   - Sélectionnez « Mistral AI »
   - Dans le navigateur ouvert, entrez votre adresse CNRS pour être redirigé vers Janus

</div>

</div>

<div class="t-label" style="color: var(--orange); border-top: 1px solid var(--navy-light); padding-top: 0.75rem;">Lancement et documentation</div>

4. Lancer **vibe** dans un terminal ouvert sur votre dossier de travail

**Pour aller plus loin**{.badge-orange}

Documentation : docs.mistral.ai/vibe/code/cli/work-with-cli

</div>
